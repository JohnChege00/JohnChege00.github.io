01 / major project

Enhanced Online Student Clearance System

A web-based student clearance and graduation application system built to replace a manual, paper-based process.

In development

Problem

Student clearance and graduation applications are traditionally handled on paper, moving between departments for sign-off. That process is slow, hard to track, and easy to lose paperwork in.

What I built

A full-stack web application that moves clearance and graduation applications online. Students submit applications and track their obligations, while departmental and finance staff review and clear them digitally instead of on paper.

Key functionality

  • Online student clearance workflow across departments
  • Graduation application submission and tracking
  • Obligations checking before clearance is granted
  • OCR extraction of KCSE certificate information
  • QR-based verification of cleared documents
  • Timestamps and audit logs for every action taken
  • PDF generation for cleared documents and certificates
  • Separate student and admin workflows
  • Finance clearance and departmental clearance stages

Technology stack

Node.js Express.js PostgreSQL EJS HTML CSS JavaScript OCR QR Verification Audit Logging

03 / major project

Vulnerability Scanner

A Python security scanner that runs reconnaissance and active exploit-testing modules against a target site from a single dashboard.

Completed Repository not yet public

Problem

Checking a site for common security issues usually means running several separate tools by hand: one for exposed files, another for secrets, another for injection flaws. There was no single place to run those checks and see results as they came in.

What I built

A Python-based vulnerability scanner with a scan dashboard that groups checks into Recon and Exploit categories, runs them against a target, and streams results live: pages crawled, requests made, and vulnerabilities found as the scan runs, with a live log, a vulnerabilities list and a summary report.

Key functionality

  • Info disclosure checks for exposed configuration files and backups
  • Secret finder for exposed API keys and tokens
  • API discovery for hidden endpoints and GraphQL schemas
  • SQL injection testing using error-based and time-based detection
  • Business logic testing for price and quantity tampering
  • JWT cracker for weak secrets and the "none" algorithm flaw
  • DDoS resilience testing through concurrent load testing
  • Integrity monitoring for defacement detection
  • Live dashboard tracking pages, APIs, requests, vulnerabilities and scan duration

Technology stack

Python SQL Injection Testing JWT Security Secrets Detection API Discovery Load Testing
